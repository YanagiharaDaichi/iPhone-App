類似画像検索

はじめに Google Cloud Vision API の API キーを設定してください。

画像を選んで検索

ここに画像をドロップするか、貼り付け(Ctrl+V / ⌘V)でも検索できます

選んだ画像は検索のため Google Cloud Vision API に送信されます。

設定

キーはこのブラウザ内にだけ保存され、検索のときに Google へ直接送られます。空にして保存すると削除されます。

API キーの作り方
  1. Cloud Vision API を有効にする(課金の設定が必要です)
  2. 認証情報 で「API キー」を作成する
  3. キーの制限で「ウェブサイト」にこのページのアドレスを登録し、使える API を Cloud Vision API だけにする(推奨)
